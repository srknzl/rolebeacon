      Opportunity-fit point distribution
      
Distribute all 100 fit points. A larger value makes that factor influence ranking more; zero removes it from fit ranking. Eligibility remains a separate hard deterministic gate, so no distribution can override authorization, sponsorship, clearance, or geographic restrictions.

Job scoring sends summary, current location, experience, projects, skills, education, and search preferences to the configured model. Email, phone, website, GitHub, LinkedIn, and other contact details are excluded.

    

      
      
      
    

    
    

    
Rules-only scoring is selected until you choose and test an LLM endpoint.

    
Starting Ollama or downloading a model happens only when you click the corresponding button. qwen3:8b is the shipped default but not yet measured on this project's rubric; qwen2.5:14b-instruct-q6_k is the measured recommendation on hardware with enough memory (via rolebeacon evaluate-model - qwen3:14b's reasoning behavior scored worse on this rubric despite being larger).

    
Scoring prompts run 2-8k tokens depending on posting length. A self-hosted Ollama needs OLLAMA_CONTEXT_LENGTH set to at least that (RoleBeacon requests 16384 tokens of context per call), or long postings are silently truncated before scoring - this is a setting on your Ollama host, not something RoleBeacon can set for you.
